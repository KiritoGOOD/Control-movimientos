CONTROL DE MOVIMIENTOS - PWA (0 USD)

Qué incluye:
- Carga rápida de Nombre, Ingreso, Egreso y Observación
- Historial
- Resumen general
- Resumen agrupado por persona
- Edición y eliminación de movimientos
- Búsqueda
- Exportación a CSV para abrir en Excel
- Backup/restore en JSON
- Funciona offline después de instalarla
- Datos guardados localmente en el dispositivo

IMPORTANTE
Para que se pueda "instalar" como app (PWA), debe abrirse desde HTTPS o localhost.
La opción gratis más sencilla es subir estos archivos a GitHub Pages.

Pasos rápidos con GitHub Pages:
1. Crear una cuenta gratis en github.com
2. Crear un repositorio nuevo, por ejemplo: control-movimientos
3. Subir todos los archivos de esta carpeta
4. Ir a Settings > Pages
5. En "Build and deployment" elegir "Deploy from a branch"
6. Elegir branch "main" y carpeta "/ (root)"
7. Guardar
8. GitHub mostrará una dirección https gratuita
9. Abrir esa dirección en el celular
10. En Android/Chrome: menú > "Agregar a pantalla de inicio" o "Instalar app"

Los datos NO se suben a GitHub. Se guardan solo en el navegador del celular.
